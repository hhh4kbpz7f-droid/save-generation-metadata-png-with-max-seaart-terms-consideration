save-generation-metadata-png-with-max-seaart-terms-consideration
バージョン 0.1.9

これは何か
SeaArtの創作画面で、開いている1枚と、その画面に出ている生成情報から、生成情報入りのPNGを作って端末へ保存するユーザースクリプトです。

SeaArtの利用規約への配慮
このスクリプトは、SeaArtの利用規約に最大限の配慮をして作っています。人が開いた1枚だけを、その画面の表示から保存します。ページの自動操作や、画像のまとめ取りはしません。これは、規約に適合しているという意味ではありません。

使い方
1. iOSのSafari拡張「Userscripts」を入れ、Safariの拡張機能で有効にする。
2. 同梱の .user.js を Userscripts に入れる。
3. SeaArtの創作画面で、保存したい画像を開く。
4. 画面の ℹ️ を押し、生成情報を開いたままにする。
5. 右下の PNG を押し、「PNG生成&保存」を押す。
6. 「生成情報入りPNG完成」のあと、共有シートが開く。保存先を選ぶ。
7. 保存が終わると「生成情報入りPNG保存完了」と出る。共有シートを閉じたときは「キャンセル」と出る。

このスクリプトがしないこと
- ページ上のボタンは押さない。
- 画像をまとめて取得しない。
- 通信は、画面に出ている画像のURLへGETする1回だけ。
- プロンプトやCookieヘッダは、スクリプト自身では付けない。Userscriptsが画像ホストのcookieを添える余地はある。
- 生成情報やアカウント情報を、スクリプトから別のサーバーへ送らない。
- 共有シートは端末の機能である。メールなどへ送るかは、シートで選んだ先の操作による。
